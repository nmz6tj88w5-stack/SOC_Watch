# Knowledge Index

Routes to domain-specific knowledge folders. Each domain folder contains:
- `knowledge.md`   → confirmed facts and patterns
- `hypotheses.md`  → things that need more data (promote to rule at 3+ confirmations)
- `rules.md`       → confirmed rules, applied by default

## Domains

- [soc-watch-app](soc-watch-app/) — the "SOC Watch" SwiftUI idle game (tower-defense reskinned as a Security Operations Center). Covers UI verification findings, GameEngine behavior, and device-testing methodology for this specific app.
